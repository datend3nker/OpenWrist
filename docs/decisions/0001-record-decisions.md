# 0001: Record decisions as ADRs

- **Status:** accepted
- **Date:** 2026-10-09

## Context

Much of the code is written with AI assistance. The reasoning behind it often
lives only in a chat transcript and gets lost.

## Decision

Larger decisions are recorded as short Markdown files in `docs/decisions/`
(Architecture Decision Records).

## Consequences

- Anyone asking "why is it like this?" later finds the answer in the repo.
- A little more writing per decision.
