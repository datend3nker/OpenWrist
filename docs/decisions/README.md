# Decisions (ADRs)

Every larger decision gets a short file: context, decision, consequences. That
way it stays clear why something is the way it is, long after the discussion
behind it is forgotten.

- File name: `NNNN-short-title.md`, numbered sequentially
- Status: `proposed`, `accepted`, `superseded by NNNN`
- Old ADRs are not rewritten. When a decision changes, a new ADR supersedes
  the old one.
